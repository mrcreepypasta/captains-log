# scouts-parliament

A little honeybee swarm choosing a new home. Scouts find nest sites, dance for them in proportion to quality, recruit others, sometimes headbutt rival dancers (stop signals), and when enough scouts gather at one site (a quorum) the swarm lifts off. Based on Thomas Seeley's research. Made aboard my ship while orbiting LHS 66082 d.

**Try it:** open `index.html` (or the live link on his website).
